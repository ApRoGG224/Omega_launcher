# Проблема: Блокировка создания новых окон в Tauri v2

## Суть проблемы
При попытке запустить отладочное окно (Debug Window) через функцию `handleCreateInstance`, окно не появлялось, а логи никуда не выводились. Внешне это выглядело так, будто функция дебага не работает или игнорируется.

## Что именно работало не так
В коде фронтенда (React/TypeScript) был прописан правильный вызов для создания нового окна:
```typescript
const debugWin = new WebviewWindow('debug_window', {
  title: 'Создание сборки - Дебаг',
  width: 600,
  height: 400,
});
```
Однако в новой версии **Tauri v2** кардинально переработана система безопасности (Capabilities). По умолчанию Tauri считает веб-интерфейс (JavaScript) потенциально уязвимым и запрещает ему выполнять любые системные действия, включая:
1. Создание новых нативных окон.
2. Использование системных API.
3. Отправку событий между окнами, если окно не зарегистрировано в конфигурации.

Из-за этого Tauri молча блокировал запрос на создание окна, так как у фронтенда не было соответствующих прав (permissions).

## Решение
Для исправления ситуации потребовалось внести изменения в конфигурационный файл безопасности Tauri — `src-tauri/capabilities/default.json`.

1. **Разрешение на создание окон:**
   В массив `"permissions"` было добавлено правило `"core:window:allow-create"`. Это говорит Tauri: «Разрешить JavaScript-коду динамически порождать новые окна».

2. **Регистрация нового окна:**
   В массив `"windows"` было добавлено имя `"debug_window"`. Это даёт новому окну права на выполнение базовых операций (включая получение событий через `emit`/`listen`), которые прописаны в этом capability.

### Изменённый файл `default.json`:
```json
{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "default",
  "description": "Capability for the main window",
  "windows": ["main", "debug_window"],
  "permissions": [
    "core:default",
    "core:window:allow-create",
    "opener:default"
  ]
}
```

После применения этих настроек (и перезапуска сервера разработки) Tauri начал доверять нашему коду и успешно открывать окно дебага.
